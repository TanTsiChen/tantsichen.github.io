Agent tools & infrastructure

AI agents rely on software to turn model outputs into actions and bring tool results back into context. I develop tools and infrastructure for making these interactions explicit and reliable, with attention to data representation, execution, and verification. The projects here address practical problems in agent workflows and are released as reusable software.

Selected tools

  • DSH Exact Integers

    TypeScript · MIT

    An opt-in plugin for DeepSeek Harness that preserves arbitrary-precision integers in tool arguments and results. Tool code works with JavaScript bigint, while explicitly declared fields use decimal strings when exchanged with the agent or stored in sessions. The package provides validation and native JSON adapters, with tests covering tool execution, persistence, replay, and cancellation.
